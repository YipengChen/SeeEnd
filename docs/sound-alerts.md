# 音效提醒（0.8.61）

在「提醒偏好 → 提醒方式」开启「音效提醒」，选择音效类别。默认关闭，音量跟随系统；试听不受开关限制。

下拉框和「试听」位于「音效提醒」问号图标右侧，同一行排列；不再显示单独的「音效类别」文字，类别选择仍保留无障碍名称。

内置三种短音效：柔和铃声（1.10 秒）、清脆提示（0.38 秒）、小猫夹子音（约 0.87 秒）。铃声与提示音为 SeeEnd 原创合成，由 `packaging/generate_sounds.py` 生成。猫叫使用真实小猫录音，将播放速度及音高调至 1.18 倍（约提高 2.9 个半音），让叫声更轻细；统一输出单声道 24 kHz / 16-bit PCM WAV。全部资源随安装包离线提供。

猫叫原作者 nathan-osman，作品 [meow-1.wav](https://freesound.org/people/nathan-osman/sounds/686775/)，[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) 许可。输入使用该作品的公开 MP3 预览，浏览器 Web Audio OfflineAudioContext 解码后以 1.18 倍播放速率渲染、合并单声道，峰值归一化到 0.43，并添加 5 毫秒淡入、8 毫秒淡出。替代上一版较低沉的成年暹罗猫叫。

仅真实任务的完成和等待输入事件触发一次。声音独立于灯具、灯光亮度及系统通知权限；演示、自检、已禁用来源、重复和过期事件不播放，重启不补播。关闭开关会停止当前音效并清理排队请求。

macOS 使用系统 afplay；Windows 使用 winsound 异步播放；Linux 需要 paplay 或 aplay。无法播放时，偏好页显示错误并保留试听重试。活动记录中的音效回执只说明播放提交结果，不能确认用户实际听到声音。
