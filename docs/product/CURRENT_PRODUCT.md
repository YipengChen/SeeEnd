# SeeEnd 当前产品基线

基线：App 0.8.6、浏览器扩展 0.2.10、事件协议 1.0、Skill 1.0.1。操作说明以 [使用指南](../quick-start.md) 为准，构建与仓库配合见 [协作与发布](../REPOSITORIES.md)。

当前产品是本机 AI 任务提醒应用。首次启动默认虚拟模式；可独立使用屏幕烛火、托盘与桌面通知，也可连接多台 Yeelight YLTD003 或 YLDP005。实体设备按状态设置颜色与亮度，使用原厂 LAN 协议。

来源包括六种原生编程工具、九个平台的实验网页适配、四种 macOS 实验桌面客户端和本地 API。接入与真实验收分别记录：配置就绪、收到开始、同一新任务结束及各输出投递不能互相替代。特殊模式、系统权限、浏览器冻结、真实硬件发光和其他平台仍按其实际证据确认。

统一事件按来源、任务和序号处理；取消、未知和异常不视为成功。事件可指定设备，省略时广播；任务整体状态仍按全部活动任务汇总。数据与任务生命周期元数据在本机处理，事件历史保留七天、最多 10,000 条；秘密字段不进入分发材料。

原创实现采用专有许可，第三方材料保留各自许可。公开安装包包含运行依赖与许可文本；第三方源码和构建材料独立按需下载。

本目录其他 PRD 和竞品方案研究是历史资料，描述旧灯板、USB、规则配置、固件与未来路线，不作为当前已实现需求或发布承诺。
