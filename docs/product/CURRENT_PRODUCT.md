# SeeEnd 当前产品基线

基线：**App 0.8.69、浏览器扩展 0.2.14、事件协议 1.0**。版本以 `aiflame/__init__.py`、`pyproject.toml` 和扩展 `manifest.json` 为准；源码与本机构建不代表已公开发布。操作见[使用指南](../quick-start.md)，协作与发布见[仓库说明](../REPOSITORIES.md)，验证证据见[验证说明](../validation.md)。

## 已实现范围

SeeEnd 是本机 AI 任务提醒应用，无需实体设备或向 SeeEnd 提供模型 API Key。提醒只区分工作中、等待输入、已完成，另保留待机、取消、超时和未知生命周期。旧 `error` 兼容为 `unknown`，不触发独立失败灯效或失败通知。产品不提供暂停或定时静默。

系统通知、音效提醒、微信通知、桌面火焰、设备提醒五个通道独立开关，可同时使用。首次启动／重置只开启桌面火焰；系统通知需实时权限校验，微信需绑定与准备连接，设备需单独连接。保存成功保持安静；保存失败恢复对应开关，在问号及悬停提示解释原因和重试方式。已有偏好保留。

接入包括六种编程工具（Codex、Claude Code、Qoder CLI、DeepSeek Harness、Gemini CLI、OpenCode）、九个平台的实验网页扩展及本地 HTTP API。编程工具安装、验证、诊断和维护统一通过 SeeEnd Skill；App 来源开关不承担安装。手动与模拟任务仅作诊断，不计入真实接入验收。当前不提供桌面客户端监测接入。

设备范围由 `devices/models.py` 定义：

| 型号 | 当前能力 |
| --- | --- |
| Yeelight YLTD003 | 背部彩灯、前部白灯 |
| Yeelight YLDP005 | 整颗彩灯、白灯 |
| Yeelight YLFWD-0021 Beam | 双塔彩灯、RGB 模拟白灯 |
| Yeelight Cube Lite | 像素状态牌、彗星巡航、贪吃蛇、文字状态及整屏彩灯／白灯 |
| 米家智能插座 3（ZNCZ301KK）／4（ZNCZ401KK） | 按状态通断电 |

设备保留原厂程序，SeeEnd 不提供 USB 刷写、旧灯板协议或固件维护。多台设备独立保存连接、状态参数和回执。工作中／等待输入的真实任务阻止所有试亮与演示，新任务会抢占预览；无在线设备仍可做屏幕演示。设备状态卡提供当前设备的 15 秒状态试亮，修改参数自动保存并同步。

Cube Lite 使用单个持续 UDP 会话发送灯效和控制，每分钟验证真实控制回执；无回执则停止发送并退避恢复。2026-10-17 用户完成长时间实物测试并确认正常，长期卡死问题按用户验收判定已修复，见[排查记录](../cube-lite-health-0.8.57.md)。像素帧仅报告已发送，不冒充设备显示确认。

## 任务、界面与返回

总览显示任务状态、应用接入和最近动态；窄窗口自动纵向排列。macOS 已有终端进程身份的未结束任务，在确认宿主退出或 PID 复用后转为 unknown；进程信息不完整时保持原状态，可在活动详情将单个残留任务标为状态未知。主窗口为原生 Qt Widgets，不加载 WebEngine，支持中英文。窗口隐藏后后台 Hub 与提醒继续运行，桌面火焰可拖动、双击返回任务。活动记录按任务汇总，详情区分灯光和各通知通道回执，可复制任务标识及导出 CSV。

用户可从最近动态、记录详情、macOS 系统通知或双击火焰返回对应任务。网页由原浏览器配置中的扩展定位或恢复正式会话地址；终端支持本机 Terminal／iTerm2，首次需要自动化授权。普通 Codex CLI 以当前活进程、名称和完整目录唯一匹配，共享 daemon 下不保证历史会话 ID 与当前客户端一一对应，旧记录可能指向同名新会话。无法确认的位置拒绝返回，不读取终端或聊天正文。

## 数据、兼容与验收边界

Hub 默认只监听回环地址并使用凭据鉴权；桌面与 Skill 使用同用户私有 dashboard 凭据验证服务身份并签名管理请求，根凭据不通过 HTTP 发送，来源令牌不能取得管理权限。事件按来源、任务和序号处理；未知与未正常结束不推断成功。任务状态、偏好和返回标识在本机保存，历史最长 7 天、最多 10,000 条。网页会话 URL 仅在扩展本地缓存，最长 7 天、最多 1,000 个位置。微信开启后将来源、状态与时间发送到腾讯服务。

macOS 设备 Token 使用本机 AES-GCM 文件加密，Windows 使用当前用户 DPAPI；微信凭据另行存储。凭据和本机密钥不随源码或分发包公开。沿用 `aiflame` 包名、用户数据目录、应用与桥接标识、旧 CLI 别名，迁移时保留兼容设备和偏好。

配置就绪、收到开始、同一新任务完成、输出被接受和用户实际看到提醒是不同证据。模拟测试不能代替真实工具、账号、系统权限、物理灯光或其他平台验收；历史结果只适用于其明确记录的版本和场景。
