## 从 Chrome 商店安装

普通用户安装 [SeeEnd 商店版](https://chromewebstore.google.com/detail/miokmdeomlchjpihkcnommpnheagoimc)。截至 2026-10-10，商店 0.2.8 已通过审核，以不公开分发方式发布；本目录的 0.2.12 是源码／开发版本，尚未提交商店；0.2.10 的送审状态另见项目状态记录。

1. 在桌面 App 打开「应用接入 → 安装浏览器扩展」，点击第 1 步的「在 Chrome 安装扩展」打开商店安装地址。点击「添加至 Chrome」并确认安装。
2. 回到 App 勾选「我已在 Chrome 安装并启用 SeeEnd 扩展」，点击「继续」。已安装的用户可直接确认。
3. 选择常用网站，点击「允许连接」；若该网站提醒关闭，点击「开启此网站提醒」，然后点击「完成设置」。也可通过「在 Chrome 打开」前往网站。
4. 登录并刷新 AI 网页后即可使用。发送一条新的普通文字提问，SeeEnd 会随任务进度自动提醒。已有对话中的新提问也可追踪；已完成的历史任务不会补发提醒；固定扩展图标可选。

无需开发者模式、下载解压、灯具或模型 API Key。商店版由 Chrome 自动更新。升级或移动 App 后，在引导中重新允许连接，再刷新 AI 网页。0.8.6 及更早的已发布 App 仍显示旧安装引导；也可先从上述商店链接安装，再回旧引导的网站连接阶段注册桥接。

扩展使用商店 ID `miokmdeomlchjpihkcnommpnheagoimc`；桥接继续兼容旧开发 ID `hifannlfdbbhmmgecknoakpbhfihihbg`。

## 源码／开发加载

开发者可在 `chrome://extensions/` 开启开发者模式并加载本目录，运行 `python -m aiflame.integrations.chatgpt_web.install --browser chrome` 注册桥接。保留已加载的目录；更新开发文件后重新加载并刷新网页。Edge 使用 `--browser edge` 和 `edge://extensions/`，实机仍待验证。Windows 桥接需要打包 App 中的 `SeeEnd Bridge.exe`。移动 App 或出现 `bridge_update_required` 后重新连接桥接。

## 状态规则与隐私

- 点击发送或在输入区按 Enter 后，必须观察到明确生成控件，才发送 `working`。后台打开旧会话、扩展加载前已在生成的任务不接管。
- 有生成控件，或已确认同一条新回复仍无结束控件时，每 30 秒续期。只有在本次任务开始后观察到新的回复结束操作控件，并持续确认 800 毫秒，才发送 `done`；不依据回答文字停顿推断成功。
- 支持新会话地址切换、ChatGPT / Kimi 临时会话地址与智谱按查询参数区分的会话。停止、断网、切换会话、刷新或关闭标签页撤销任务。120 秒观察中断或最长 30 分钟任务超时都不会提示成功。
- 扩展后台校验精确 HTTPS 来源及主框架，将网站与来源 ID 绑定，拒绝跨平台冒用。页面、扩展不持有 Hub 令牌；桥接只使用对应网页来源的凭据。
- 不读取、保存或发送提问、回答、输入框内容、会话标题、账号或模型信息。控件属性与回复标识在页面内检查；任务会话地址和原标签页位置另保存在扩展本地，最多七天／1,000 项，供用户主动返回。发送给桌面应用的事件不包含实际地址、回复标识或正文。
- Hub 不可达后停止该页面的转发，不补播历史完成；恢复后刷新页面再发起新任务。

## 后台标签页

扩展自 0.2.5 起由后台 service worker 每 5 秒唤醒已开始的原始文档，当前九个平台共用该调度；不依赖隐藏页面自己的轮询计时器。千问和智谱还在页面脚本之前安装 `frames.js`：仅在可信提交已登记、任务进行中且标签隐藏时，推进网站等待中的动画帧，并按原始频率补偿不超过 100 毫秒的短周期渲染定时器，使完成控件能正常渲染。每个周期的补偿最多执行 250 次回调，取消与原生计时器编号仍保持一致；不超过 100 毫秒的一次性短延时只在原定截止时间已到后唤醒，每次最多 250 个或 25 毫秒，递归短延时按原定时间顺序推进；不补偿长周期定时器。切回前台沿用原生动画帧；取消、结束或 45 秒未收到任务续期信号后停止后台推进。任务空闲后停止后台轮询。

智谱还会主动暂停回答渲染：仅捕获官方前端中具有特定静态标记的回答渲染回调，已登记后台任务期间按至少 5 秒间隔恢复，保留逐字输出完成步骤的执行窗口；该同步回调内临时提供 `visible` 状态，立即恢复页面属性，不派发全局可见性事件、不调用其他监听器。连续等待帧的渲染按批推进，每批最多 300 帧或 50 毫秒，并在帧之间允许网站完成微任务。诊断只显示待处理数量和执行次数。

完成仍须匹配本轮回复的新结束控件并持续确认 800 毫秒。扩展不激活标签、不读取网络响应或正文，不新增浏览器权限。睡眠、冻结、标签被丢弃和浏览器退出期间不能保证采集。

## 验证范围

2026-09-30：新增六个平台的控件规则参考各官方网页公开发布的前端脚本和样式，包括 DeepSeek 图标按钮、千问回复操作栏、豆包 `data-testid` 控件、元宝无障碍标签、Kimi 回复操作栏、智谱可用反馈控件。使用精简 DOM 结构做了开始／完成、旧回复不重播、停止／切换取消、隐藏／禁用控件、重复生成复用 DOM、来源隔离和正文不可读取的回归测试。Python 桥接、独立凭据、设置迁移及本机 HTTP 通路均有自动化测试。

2026-09-30 后续真实页面复测：用户手动新建并恢复独立 Chrome 测试窗口后，在该窗口发送测试提示词；七个平台均观察到真实 `working → done`，本机记录确认完成事件 `applied`，已排除模拟自测。ChatGPT、智谱请求 500 行数字，其他平台请求 300 行数字；豆包、智谱、元宝使用未登录界面。111 项浏览器回归及 74 项 Python 回归通过。这些结果不等于全部模式、所有浏览器或全部硬件行为已验收。

DOM 可能随平台更新。未识别结束控件时保持不确定并最终超时。错误控件覆盖有限；图片、语音、Agent、深度研究等模式没有完整验收，不保证覆盖。可用输入控件不代表完成控件一定兼容，需结合真实任务测试。

- ChatGPT 新版界面不再始终提供助手消息角色属性；备用操作栏只识别助手复制控件，避免将用户消息复制／编辑栏绑定为回复。

### 0.2.2 共用检测层

- 所有平台共用 `detector.js` 的控件检测、回复标识、结束控件状态，以及 `state.js` 的任务生命周期；各站点只保留控件和路由配置。共享层的修复无需逐站复制。
- 长输出持续观察生成控件并每 30 秒续期；完成需要当前任务的新结束控件，不能按文字长度、停顿或等待时长推断。
- 工具栏重建不会重置同一条回复的完成判断；页面具有稳定回复标识时，回复节点重建也能维持身份。没有稳定标识而丢失回复节点时保持不确定。
- 最新回复暂时隐藏或被虚拟列表移除时，不采用历史回复作为完成依据。布局仍存在的离屏控件无需滚动就能识别；已被网页移除或尚未渲染的控件不能凭空检测。
- 空闲页面不持续扫描对话 DOM。七个平台执行同一组 12 分钟长输出、回复与工具栏重建、虚拟列表、离屏控件和长输出取消的结构测试；真实网页登录态复验仍待完成。
- 升级时须包含新文件 `detector.js`，重新加载扩展并刷新聊天页面；弹窗版本应为 `0.2.2`。

## 逐站验收

1. 普通文字消息：工作状态 → 回复结束完成提醒约 10 秒 → 恢复其他工作或熄灭。
2. 长任务点击停止：登记取消，不出现该任务完成提示。
3. 生成中切换会话、刷新、关闭页面：取消或租期失效，不提示成功。
4. 两个平台／两个标签页同时生成：各自登记，关闭或取消一个不影响另一个。
5. 仅加载历史回复：不触发完成。
6. 关闭 Hub 后生成，再恢复 Hub：不补播，刷新网页后开始新任务。
7. 在桌面 App 的「应用接入」关闭一个平台来源：该平台事件不触发，其他平台仍可使用。

「设置与帮助」中的桥接测试是明确标记的模拟任务，只验证桥接和 Hub。`queued` 表示 Hub 已收到；`applied` / 设备已确认表示灯具协议已确认调度。实际发光需观察硬件。

## 测试与卸载

在本仓库目录运行：

```sh
python -B -m unittest discover -s tests -v
npm ci --ignore-scripts
npm test
```

浏览器扩展可从扩展管理页移除；桥接卸载命令为：

```sh
python -m aiflame.integrations.chatgpt_web.install --uninstall
```

仅移除本项目原生桥接注册，保留其他浏览器配置、Codex 接入及任务历史。也可只在桌面 App 的「应用接入」停用需要关闭的平台。

桥接机制参考 [Chrome Native Messaging](https://developer.chrome.com/docs/extensions/develop/concepts/native-messaging) 和 [Content scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)。DOM 规则是本项目实验适配，不属于各厂商官方完成事件接口。
