# 0.4.6 完整视频复核：吹散与横向倒伏（2026-10-04）

> 本文保留历史版本的本机验收证据。原始参考视频与硬件备份不随开源源码分发；备份路径仅用于追溯当时的操作。当前使用方式与支持范围以 README 和使用指南为准。

用户反馈 0.4.5 仍不像参考：旧模型每行只有一个亮度峰，只能缩短完整火苗，无法表现被风吹散；上一轮稀疏抽帧漏掉了中间的短动作，判断不足。

本轮检查完整 76.2384 秒视频，按 0.2 秒间隔提取并检查全部 381 帧；再以 25 fps 检查 12.9–16.26 秒的 85 帧。完整参考联系表保存在 `reference-full-analysis/reference-00.jpg` 至 `reference-04.jpg`，覆盖全片而非只看开头。
