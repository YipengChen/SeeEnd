# 0.8.14 新设备支持

> 版本记录：以下结论对应标题版本；当前能力及验证边界见 [产品基线](product/CURRENT_PRODUCT.md) 和 [验证入口](validation.md)。

- 米家智能插座 4：ZNCZ401KK，协议型号 `xiaomi.plug.04`。沿用插座 3 的任务状态通断电规则、凭据保存、重连与退出熄灯流程。扫码保留两代设备的型号，界面只展示当前选中型号。
- Yeelight Cube Lite：新增 20×5 整屏彩光和 RGB 模拟白光，分别保存设置；复用任务状态颜色、亮度、白光色温及关注状态闪烁。待机、提醒到期和正常停止发送全黑帧。
- Cube 使用 TCP `activate_fx_mode` / `update_leds`，与 Beam 的 UDP 会话分开。每帧 100 个 RGB 像素；最多每秒 10 帧。错误回执和断线触发重新识别与初始化。直接帧只能确认发送，不能声称灯具已执行。
- 发现限定 `cubelite`、`CubeLite`、`clt4`、`yeelink.light.clt4`，同时校验控制能力、来源 IP 和设备 ID；没有按名称或任意 `clt*` 前缀放行其他尺寸的灯具。
- 当前验证范围：模拟协议、设备服务、持久化与桌面流程。未连接两款实物；不同固件的局域网开放情况及灯光表现仍需实机确认。

协议依据（2026-10-16）：

- MIoT `xiaomi.plug.04` 的已发布实例：<https://miot-spec.org/miot-spec-v2/instance?type=urn:miot-spec-v2:device:outlet:0000A002:xiaomi-04:1:0000D032>；开关属性为 SIID 2 / PIID 1。
- Cube Lite 协议行为参考原作者实现：<https://github.com/Max-src/yeelight-cube-lite>。SeeEnd 未引入其依赖或复制实现，使用现有局域网客户端独立实现所需命令。
