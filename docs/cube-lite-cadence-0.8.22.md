# Cube Lite 彗星节拍与折返连续性 0.8.22

> 版本记录：以下结论对应标题版本；当前能力及验证边界见 [产品基线](product/CURRENT_PRODUCT.md) 和 [验证入口](validation.md)。

用户确认 0.8.21 已无状态闪回，但仍偶有卡顿。

本次修正：
- 彗星拖尾按光点实际经过的轨迹延迟跟随，取消折返时整条拖尾瞬间换侧。起始拖尾从屏幕外连续进入。
- Cube 发送与动画刷新共用同一 100 ms 时间表，消除每帧处理时间累加；错过完整时间槽时重新等待一帧，不集中补发。保持名义 10 FPS。操作系统调度允许单个帧间隔略短于或长于 100 ms。
- 保留发送前状态复核、非阻塞心跳及点阵上下方向修正。

验证：110 项相关测试通过，最后调整起始拖尾后重跑 11 项灯效测试通过。测试覆盖折返连续性、处理耗时不累积、严重延迟不集中补帧。

同一台机器、本地 UDP 模拟灯具、连续工作状态 20 秒，心跳回执故意延迟 650 ms：

| 指标 | 0.8.21 | 0.8.22 |
| --- | --- | --- |
| 非黑画面数 | 192 | 201 |
| 平均 FPS | 9.573 | 9.999 |
| 帧间隔中位数 | 104.385 ms | 100.040 ms |
| 帧间隔 P95 | 108.074 ms | 104.368 ms |
| 最大帧间隔 | 140.270 ms | 115.516 ms |

折返点前后各 0.1 ms 的 RGB 字节绝对差：修正前 888，修正后 0（整数字节量化）；证实原实现存在画面跳变。

以上为本地模拟接收端数据，不是实际灯具的显示测量。无线链路丢包、灯具缓存和肉眼体感仍需用户更新后验证。
