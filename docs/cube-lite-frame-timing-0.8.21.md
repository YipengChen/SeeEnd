# Cube Lite 动画时序修正 0.8.21

> 版本记录：以下结论对应标题版本；当前能力及验证边界见 [产品基线](product/CURRENT_PRODUCT.md) 和 [验证入口](validation.md)。

用户反馈：彗星试亮偶发卡顿，状态显示偶尔短暂闪回。

代码中确认的风险：运行中心跳等待回执与像素发送共用线程，最多阻塞两秒；状态复核之后还可能等待 direct 模式初始化；像素在限速等待之前已生成。尚未证明用户看到的每次闪回都由这些路径导致。

修正：运行中心跳采用非阻塞接收、独立请求 ID 匹配、两次同 ID 重试与两秒超时。首次建会话仍要求真实回执。像素发送前先完成限速及初始化，再在状态锁内复核、按当前时间生成画面并发送；失效画面不发送。保持 10 FPS 上限及上下方向修正。

验证：108 项相关测试通过。另以本地 UDP 模拟灯具运行正式发送线程 14 秒，人为将运行中心跳回执延迟 650 毫秒；收到 100 个非黑帧，状态顺序为 working → needs_input → done，没有倒退。发送间隔中位数 105.15 毫秒，最大 244.73 毫秒；静止画面会合并并约每 200 毫秒刷新，所以此最大值并非纯动画帧间隔。两次心跳含重试，连接保持在线。

本轮未接管实际灯具。UDP 帧无逐帧确认；网络乱序、灯具缓存或其他控制器造成的闪回仍需实物观察，不能以本地模拟测试宣称消除。
