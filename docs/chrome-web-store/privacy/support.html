SeeEnd 安装与帮助

SeeEnd 将 AI 任务状态变为本机提醒，没有灯具也能使用。

下载 SeeEnd

0.8.56 桌面预览版 · macOS Apple 芯片

只需下载此安装包。已包含 App 和运行依赖，解压后启动 SeeEnd.app 即可。

安装与连接

  1. 解压下载的安装包，启动 SeeEnd.app。该预览版尚未经过 Apple 公证；无法启动时请联系发布者。
  2. 保持 App 运行，在“应用接入”中选择要使用的应用。编程工具复制 Skill 安装指令；网页点击“安装浏览器扩展”，按四步引导完成连接。
  3. 安装并启用浏览器扩展后，刷新受支持的文字对话页面，发起一条新消息。
  4. 在扩展弹窗检查当前页面和桥接连接，在 SeeEnd 活动记录查看生成及完成状态。没有灯具也能检查状态；灯光提醒需另行配置设备。

常见问题

“找不到本机消息宿主”：保持桌面应用运行，打开“安装浏览器扩展”引导，在“连接并验证网站”阶段重新连接，再刷新对话页面。

“页面未识别”：使用普通文字对话模式，刷新页面后发起新消息。网站改版和特殊对话模式可能影响识别。

“设备离线”：先验证任务状态和活动记录，再检查设备及网络配置。
