# Yellow Argon 修复记录

2026-10-09，商店后台显示扩展 0.2.8 被拒绝。原因：中文商品说明中枚举九个兼容平台，被判定产品说明含过多关键字。反馈要求移除过多关键字并重新提交。

修复：中文详细说明从 836 字缩短为 489 字，删除平台名称列表，以实际功能、安装步骤、隐私和兼容限制描述产品；英文备份文案也删除同类长列表。保留安装包链接、公开联系方式及桌面应用依赖说明。

本次只修改商店元数据和资料文件，不修改程序、扩展包、权限或运行资源。继续使用原 0.2.8 扩展和已验证的 0.8.4 桌面包。

官方纠正说明：https://developer.chrome.com/docs/webstore/troubleshooting/#keyword-stuffing

修复后保存并重新提交；实际审核状态以 APPLICATION_STATUS.md 和商店后台为准。

重新提交时额外遇到“无法访问支持网址”。已在 GitHub Pages 部署公开 support.html，替代商店支持栏中的 GitHub 文件页面，并检查匿名访问。

结果：已成功重新提交，Google 确认“已将您的扩展程序提交送审”；状态页显示“待审核”。保持不公开分发与通过后自动发布。
