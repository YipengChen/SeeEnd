# SeeEnd 编程工具接入与维护

旧版长 Prompt 已由独立 [SeeEnd Skill](https://github.com/YipengChen/SeeEnd/tree/main/skill/seeend) 取代，避免两套产品、协议和接入说明发生漂移。

将下面的安装请求发送给实际使用的编程工具：

> 请安装 https://github.com/YipengChen/SeeEnd/tree/main/skill/seeend 中完整的 seeend/ Skill，并使用它为当前编程工具接入 SeeEnd。

仅检查已有接入时，明确请求“使用 SeeEnd Skill，只检查现有接入，不修改配置”。单独调用 Skill 且没有目标时默认只读检查。

App 生成的接入方案和接口契约代表实际安装版本；Skill 的 references 按任务提供产品、接入、协议和排查资料。当前兼容组合及三仓库职责见 [仓库协作与发布](REPOSITORIES.md)。
