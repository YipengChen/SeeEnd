# SeeEnd 使用指南

以 App **0.8.67**、浏览器扩展 **0.2.14** 的当前实现为准。公开下载和商店版本可能不同，发布状态见[协作与发布](REPOSITORIES.md)及[扩展申请进度](chrome-web-store/APPLICATION_STATUS.md)。自动测试和历史实机结果的适用范围见[验证说明](validation.md)。

## 打开与升级

将 SeeEnd.app 放在固定位置（macOS 推荐「应用程序」），先退出旧版再打开新版。本机构建默认位于 `dist/SeeEnd.app`。App 内置 Hub，无需另开服务；同一用户重复启动会恢复已有窗口。

关闭窗口后保留菜单栏／托盘运行，提醒继续工作；macOS 可从 Dock 或菜单「打开 SeeEnd」恢复。菜单「退出 SeeEnd」停止本 App 启动的 Hub；独立运行的无界面 Hub 不受影响。无托盘的平台关闭最后窗口即退出。

升级保留任务、偏好及兼容设备配置，AI Flame 旧灯板记录不再加载。移动 App 后，用 SeeEnd Skill 更新编程工具接入，按浏览器扩展引导更新通信配置；重新加载工具配置并提交新任务，避免继续使用旧绝对路径。

## 先验证一条新任务

1. 保持默认「桌面火焰」开启，无需购买或连接设备。
2. 打开「应用接入」：编程工具按下节通过 Skill 安装；网页按浏览器扩展引导安装与连接。未列出的工具需自行通过本地 API 上报。
3. 在对应工具或网页发起一条新任务，观察工作中到已完成的状态变化。
4. 在「活动记录」核对同一任务的开始和完成，并查看需要使用的提醒通道是否生效。灯效演示、配置检查和模拟诊断不计入真实接入验证。

macOS 已保存原终端位置的编程任务，会在确认宿主进程退出后转为状态未知；无法确认的残留任务，可在「活动记录」打开详情并选择「标为状态未知」，仅清除该任务的进行中或等待输入状态。

取消、超时和未知结果不会记成成功；等待输入可在继续任务后恢复工作。独立的 `error` 任务状态已移除，旧接入的 `error` 兼容记为 `unknown` 并保留失败原因，不触发失败灯效或失败通知。

## 编程工具通过 Skill 接入

支持 Codex、Claude Code、Qoder CLI、DeepSeek Harness、Gemini CLI 和 OpenCode。先确认工具在当前电脑能正常回复，保持 SeeEnd 运行。在「应用接入 → 编程工具」复制安装指令，粘贴到实际使用的工具：

> 请安装此 Skill，并用它为当前编程工具接入 SeeEnd：
> https://github.com/YipengChen/SeeEnd-skill

App 0.8.67 的管理接口需要本机私有凭据，请配套使用 Skill 1.0.5 或更新版。客户端先验证本机服务身份，再签名每次管理请求；私有凭据本身不会发送到端口。无需手动复制凭据，旧 Skill 需要更新后才能管理新版 App。

安装完整的 `seeend/` 目录及其附属文件，具体加载方式由宿主决定。App 中的来源开关只控制提醒，不安装或修复配置。

随后请求“使用 SeeEnd Skill 验证当前工具的接入”，按指引重载、审阅 Hook 或重启相关进程，再发一条新任务。可使用“请只回复：SeeEnd 接入测试成功。不要读取或修改文件，也不要调用工具。”，也可验证接下来要做的任务；真实请求按工具账号计入额度或费用。

检查、诊断、修复、更新与移除均通过同一 Skill，例如“使用 SeeEnd Skill，只检查现有接入，不修改配置”。安装器增量修改 SeeEnd 自有 Hook／插件，保留其他配置。DeepSeek 的不同 Profile 要分别安装与验证；自定义配置目录应明确告知 Skill。来源记录按工具汇总，不能自动证明某个 Profile 或同品牌客户端已经通过。

接入用于本机当前用户。SSH、容器、WSL、远程后端的 localhost 不是用户电脑，不会自动读取本机配置。完成单位是一轮主回复，单次工具调用、子代理结束和历史恢复不会独立记为完成。桥接保存生命周期元数据，不读取 transcript 文件或保存提问、回答、工具参数及错误正文。

## 网页对话接入

一个扩展支持 ChatGPT、DeepSeek、千问、豆包、腾讯元宝、Kimi、智谱清言、Claude 和 Gemini 的普通文字对话。所有网页适配均为实验功能，网站改版、模型或模式差异、冻结和丢弃标签页可能影响检测。

在「应用接入 → 安装浏览器扩展」打开引导，通过「在 Chrome 安装扩展」打开[商店页面](https://chromewebstore.google.com/detail/miokmdeomlchjpihkcnommpnheagoimc)。安装后回到 App 确认，再选择网站并允许连接。刷新网页，提交新提问，核对同一任务的开始与完成。打开商店、开启来源开关或通信成功都不代表真实验证通过。

当前源码扩展为 0.2.14；商店是否已发布此版应以[申请进度](chrome-web-store/APPLICATION_STATUS.md)和实际安装版本为准。开发加载可运行 `python packaging/extension_release.py`，在 `chrome://extensions` 开启开发者模式，加载生成的版本化目录；更新后重载扩展并刷新网页。普通用户无需保留开发加载目录。Windows 桥接需要打包版提供的 Bridge 可执行文件。

网站地址、页面诊断及各平台历史证据见[扩展说明](../aiflame/integrations/chatgpt_web/extension/README.md)。

## 控制提醒方式

总览和「提醒偏好」提供五个独立开关，可同时开启，修改后保存并同步到另一处。

| 提醒方式 | 首次启动／重置 | 开启条件与行为 |
| --- | --- | --- |
| 系统通知 | 关闭 | 每次开启前校验系统权限，授权通过后才保存；完成或等待输入时通知。显示仍受系统设置和专注模式影响 |
| 音效提醒 | 关闭 | 完成或等待输入时播放一次；可选择音效并试听，音量跟随系统 |
| 微信通知 | 关闭 | 扫码绑定本人微信、给机器人发消息并准备好连接后开启；发送完成与等待输入提醒 |
| 桌面火焰 | 开启 | 无需硬件；主窗口隐藏后继续显示。可拖动定位，双击返回任务，右键打开 SeeEnd 或关闭火焰 |
| 设备提醒 | 关闭 | 开启后恢复已保存的设备连接；关闭时后台释放连接并尝试熄灭，保留配置 |

系统通知拒绝授权时，到「系统设置 → 通知 → SeeEnd」开启「允许通知」后重试。macOS 通知请使用打包 App；测试通知仅在通道已开启且权限可用时可用。微信不可用时开关关闭并禁用。

设置说明及不可用原因位于标题旁问号和开关悬停提示；问号也可点击或用键盘激活。通道保存不弹成功提示，失败恢复原值，在提示中说明原因及重试方式。其他通道仍可独立操作。

提醒时长和完成后保持亮灯在「提醒偏好」设置；颜色、亮度和白灯参数在每台设备中独立保存。既有用户设置保留，旧硬件／虚拟模式迁移为设备提醒开关。产品不提供暂停或定时静默，无需后台提醒时退出 SeeEnd。

### 微信通知（可选）

在「提醒偏好」点击「扫码绑定」，用本人微信扫码确认；需要验证码时按界面输入。账号需具备 ClawBot 能力，无需安装 OpenClaw。绑定后先给机器人发消息，可用「检查微信连接」准备通道，再开启并「发送测试提醒」，以手机实际收到为准。

仅发送应用来源、任务状态和时间，不发送聊天正文；遵循来源开关，不受设备连接或亮度影响。模拟任务和灯效演示不发送。关闭微信开关停止自动通信并保留绑定；解绑或重置删除本机绑定。重新开启不补发关闭期间的事件。

macOS 微信凭据存入系统钥匙串，Windows 使用当前用户 DPAPI，Linux 使用权限受限的本机文件。扫码或检查连接期间通知保持关闭，准备连接最长等待 8 分钟。只有用户选择绑定、检查、开启或测试时才建立相应通信，开启后持续处理通知；消息内容传给腾讯 iLink 服务。App API、活动记录和日志不输出登录令牌。微信消息正文不保存、不执行。

「已提交微信」表示接口接受，不证明手机已展示；发送超时且结果不明时不自动重发。扫码和手机收件需由本人实测，账号或服务变化可能影响可用性。

## 返回对应任务

有返回位置的真实任务在「最近动态」和记录详情提供「返回任务」，macOS 点击该任务的系统通知也可返回。双击总览或桌面火焰返回当前提醒任务，多任务进行中选择最近更新的一条。仅用户操作时切换窗口；旧记录、模拟任务和失效位置会说明原因。

网页需要支持返回功能的配套扩展（0.2.11 起）。扩展在原浏览器配置中核对并激活原任务标签页；标签页关闭、导航或浏览器重启后，若保存了正式会话地址，则在原配置中新开；不能保证滚动到某轮历史回复。原配置或桥接离线时需先恢复连接。URL 只留在扩展本地，最长 7 天、最多 1,000 个位置，不读取会话标题或聊天正文。

终端返回支持本机 Terminal 和 iTerm2。首次操作需允许 SeeEnd 控制对应终端；拒绝后到「系统设置 → 隐私与安全性 → 自动化」重新开启。无需辅助功能、录屏或完全磁盘访问权限。进程退出、标签页关闭或同实例收到另一会话的新任务后拒绝旧位置。返回只选择标签页／分屏，不恢复工具内部会话，也无法核实尚未产生事件的会话切换。SSH、tmux、编辑器集成终端和其他终端不登记返回位置。

普通启动的 Codex CLI 在返回时才只读查询会话名称、完整目录及终端原始标题，并核对当前真实 CLI 进程、TTY 和启动时间。只统计当前活终端，历史重名不阻挡；多个同名同目录活位置或读取不完整时拒绝。共享 daemon 无法可靠绑定原会话 ID 与当前客户端，旧记录可能返回同名同目录的新会话。授权后再次核对，iTerm2 同时使用 session GUID。会话名称和标题不持久化，不读取终端正文。

定位失败在主窗口浮层说明原因，2 秒消失，可重新定位或关闭；桌面火焰发起的失败会恢复主窗口。更新 App 和接入后发起的新任务才有定位元数据，旧记录无法补出原始位置。

## 连接设备

每台设备独立连接、断开、试亮、删除和保存参数。所有在线设备默认同步任务状态；浏览其他设备不会切断连接，单台断线不影响其他设备，重连不补播旧完成提醒。

| 型号 | 连接前准备 | 提醒模式 |
| --- | --- | --- |
| YLTD003 屏幕挂灯 Pro | Yeelight App 配网并开启局域网控制 | 背部彩灯、前部白灯 |
| YLDP005 W3 彩色灯泡 | Yeelight App 配网并开启局域网控制 | 整颗彩灯、白灯 |
| YLFWD-0021 Beam 塔灯 | 可用 Apple 家庭通过 Matter 配网；检查局域网接口可达 | 双塔彩灯、RGB 模拟白灯 |
| Cube Lite | 先完成灯具联网，检查原厂局域网接口可用 | 四种点阵效果、整屏彩灯、RGB 模拟白灯 |
| 米家智能插座 3／4 | 米家 App 配网；准备所属小米账号 | 按任务状态通断电 |

电脑与设备须在同一局域网。在总览开启「设备提醒」，到「我的设备」选择型号，搜索或填写 IP 连接。Yeelight 先用约 4 秒进行 3 轮组播查询，再向本轮未发现的已保存同型号设备 IP 并行补查，每次最多 4 台；每批离线地址最多额外等待约 4 秒。首次添加且没有已知 IP 的设备仍依赖组播或手动填写 IP；手动 IP 仍需发现回复确认身份与能力。搜索失败时检查局域网控制、路由器隔离、VPN 和防火墙。配网与固件升级由原厂工具完成，SeeEnd 不刷写固件。

### 彩灯、白灯与状态预览

彩灯默认工作中柠檬黄 `#FACC15`（50%）、完成薄荷绿 `#52C788`（100%）、等待输入珊瑚红 `#FF6B6B`（100%）。各状态独立设置，0% 关闭该状态的提醒，待机熄灭提醒通道。

白灯默认色温为工作中 2700K、完成 4000K、等待输入 2700K。屏幕挂灯默认亮度为 50%／100%／50%；其他白灯型号均为 50%／50%／50%。W3 色温范围 1700–6500K，其他型号 2700–6500K，以 100K 调整。Beam 和 Cube 用 RGB 模拟视觉暖冷，不是经校准的物理色温。

白灯等待输入默认闪烁，亮／灭各 0.6 秒；可关闭闪烁或分别设为 0.1–10 秒，总周期不少于 1.2 秒。彩灯和白灯配置分别保存，恢复默认只影响当前模式。100% 为软件发送的最大亮度，实际光学输出由原厂设备决定。

设备在线后，点击状态卡片展开参数并在当前设备试亮该状态 15 秒；修改参数自动保存并同步试亮。同一状态续期不重启动画，切换状态替换试亮；离开设备页、真实任务开始或断线时结束。已有未结束任务时不覆盖任务灯效。

Beam 在待机、提醒结束和正常退出时发送全黑画面，避免原厂开关灯白色渐变；黑屏时电源属性仍为 on。断网或崩溃后可能恢复原厂效果，UDP 帧已发送不证明灯点实际显示。

### Cube Lite 点阵效果

- **像素状态牌**：四格各显示一个任务，保持位置稳定；超过四个等待空位，当前提醒优先。工作中为跳动点，完成为勾，等待输入为问号。
- **彗星巡航**：工作中光点往返，完成从中心展开，等待输入时两端交替；动画不代表完成百分比。
- **贪吃蛇**：工作中吃豆增长，等待输入时停下，完成色从头传到尾后盘起；蛇长不代表任务进度。
- **文字状态**：显示 WORK、DONE、WAIT，沿用各状态颜色与亮度。

另可选择整屏彩灯或白灯；点阵效果共用彩灯状态参数，白灯独立保存。待机全黑，断网或异常退出后可能保留最后画面；软件和协议回执不能替代实物观察。

### 米家智能插座 3／4

支持 ZNCZ301KK（`cuco.plug.v3`）和 ZNCZ401KK（`xiaomi.plug.04`）。灯具自身开关保持打开，先确认恢复供电后会亮。

1. 在米家目标插座的网络／设备信息中核对 IP 和 DID；字段位置因米家版本而异，也可先重命名便于识别。
2. 在 SeeEnd 选择对应型号，按「确认设备 → 扫码登录 → 核对连接」操作。IP／DID 可选填；扫描只能识别设备，不提供 Token。选择与米家相同地区，用所属小米账号扫码。
3. 核对列表中的名称、IP 和 DID，目标不一致时不能连接。验证身份、型号与凭据后，仅保存选中插座的 Token。
4. 设置工作中、完成、等待输入的通断电；默认工作中关、其余开。不提供颜色、亮度、色温或继电器快速闪烁。

云登录和候选凭据只在本地短暂保留，选择等待最多 3 分钟，完成、取消或过期时清理；这不等于撤销小米服务端授权。macOS 设备 Token 使用本机 AES-256-GCM 文件加密，密钥单独保存在同一私有数据目录；持有密文和密钥仍可解密。旧钥匙串凭据尝试无弹窗迁移，无法读取时重新扫码。Windows 使用当前用户 DPAPI，不回退明文；换用户或机器可能需重新登录。微信凭据存储独立于设备 Token。

日常控制通过局域网 miIO／MIoT，无需持续云登录。删除设备清理其凭据，重置清理本机设备 Token 和密钥；旧凭据清理失败会提示并保留重试引用。待机和正常退出尝试关灯，断网或异常退出可能保留最后状态。扫码为非官方兼容实现，真实账号、插座亮灭及 Windows DPAPI 需分别验收。

## 演示、记录与本机数据

总览「灯效演示」持续 15 秒，依次工作中、等待输入、完成各 5 秒。设备提醒关闭或无在线设备时仅在屏幕播放；设备提醒开启且有设备在线时同步设备。已有工作中或等待输入任务时，所有演示和单台试亮禁用，新任务会抢占演示。屏幕演示不产生任务记录，模拟任务不算真实验证。

活动记录按任务展示，详情分别查看灯光结果、设备回执与系统／微信通知回执，可复制完整任务标识并导出 CSV。「本地状态已更新」只表示调度状态，「已提交」或协议回执不证明界面、系统横幅、手机或设备已经显示。

事件历史最长 7 天、最多 10,000 条，去重记录保留 24 小时，正在运行的任务保留至结束或租期失效。默认数据目录为 macOS `~/Library/Application Support/AI Flame`、Windows `%LOCALAPPDATA%/AI Flame`、Linux `$XDG_DATA_HOME/ai-flame`（默认 `~/.local/share/ai-flame`）。目录含凭据，不应公开；移动 App 不删除配置。开发测试可用 `AIFLAME_DATA_DIR` 隔离数据。

源码启动、测试和打包命令统一见 [README](../README.md#开发测试与构建)；模块与接口边界见[架构](architecture.md)。
