# Cube Lite 贪吃蛇提醒调整（0.8.57）

- 完成：任务完成后立即在右边三个 5×5 格分别完整显示 W、I、N，文字稳定常亮，没有前置过渡或逐笔出现；左边一格的左四列（4×5）显示迷你贪吃蛇和豆子，第五列保持熄灭，与 WIN 隔开。蛇以四像素起步，以 2 步/秒移动，每吃一颗豆增长一格；填满 20 格后停留 4 秒，再从四像素重新开始。使用用户设置的完成色和完成亮度，亮度为 0 时全程黑屏。
- 待输入：冻结同一设备上一工作帧的蛇身位置、长度和豆子位置，蛇头沿用待输入状态的呼吸反馈；等待期间不推进游戏。恢复工作时首帧保持原样，之后继续逐步移动，不累计等待时间。没有上一工作帧时使用该游戏的初始状态。
- 动画身份：每个传输实例独立；工作和待输入切换保留同一游戏。进入待机或切换灯效后新建游戏；试亮、屏幕预览与正常提醒分开。
- 界面：中英文说明与状态预览同步更新。预览使用相同的帧生成逻辑。

验证：灯效几何、WIN 文字物理行序和分格位置、迷你蛇吃豆、自定义颜色和亮度、传输状态切换、长时间等待及设备隔离使用离线回归覆盖。当前受管环境禁止本机 TCP 监听和原生 Cocoa 窗口创建，HTTP 桌面联动及实灯效果未在本次验证；Qt 离屏预览覆盖中英文与窄窗口排版。
