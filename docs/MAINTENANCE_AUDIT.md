## 后续修复：Yeelight 搜索不稳定

同日实机复现：原流程连续搜索 3 次，前 2 次各找到 YLTD003 和 YLDP005，第 3 次结果为空。原发现函数只发送 1 个 UDP 查询，等待 1.5 秒，未对漏收响应进行重试。

改为一次搜索在同一 socket 上发送 3 轮查询（间隔 1 秒），在 4 秒窗口内合并迟到响应并按物理 ID 去重。定向 IP 查询验证到目标后立即结束；重连搜索支持退出取消，不需要等待完整搜索窗口。型号、控制能力和发送方身份校验继续执行。

修改后连续 6 次只读实机搜索，每次均找到两款灯具；这是本机当前网络下的复测结果。新增 6 项回归覆盖前两轮丢包、迟到响应、多灯去重、无效或错误型号响应、短超时与搜索取消。

本次修复的完整回归：376 项 Python 测试通过（常规执行跳过的冻结生命周期测试已在新 App 上单独通过），191 项 JavaScript 测试通过。macOS Apple 芯片构建、冻结验证和分发归档已完成。
