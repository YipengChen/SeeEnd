# 排查 修复与撤销

按环境/服务、配置范围、加载信任、原生触发、事件接受、输出投递逐层定位。有明确原因后做最小修复，不同时改多项设置或循环重装。

| 现象 | 检查方向 |
| --- | --- |
| 拒绝连接、超时、端口服务不符 | App/托盘运行、监听进程、实际端口、远程/容器环境、代理。本机地址不代表用户电脑；不另开重复 Hub、不杀未知占用进程。 |
| 管理接口 401/403、authentication_failed | 本地 dashboard 根密钥、HMAC 服务挑战及请求/响应签名、管理与来源身份、Host/Origin。重置或重启后重新连接；不得输出或在线路发送根秘密，不可回退管理 Bearer/Cookie。 |
| credentials_unavailable | 确认 App 已启动，脚本与 App 使用同一用户及数据目录；核对 AIFLAME_DATA_DIR。只报告文件可用性，不转储内容、不修改权限、不自动重置。 |
| 事件鉴权失败 | Hub 与适配实际数据目录、来源 ID 对应、凭据轮换；不重建凭据解决。 |
| 404/格式问题 | 实际版本、真实路径与字段，不能直接判断需要升级。 |
| JSON 错误、同名冲突、符号链接 | 文件、错误位置和归属；原字节备份，不模板覆盖，不擅改第三方损坏配置。 |
| 文件检查通过但无事件 | 实际目录/Profile、插件服务、禁用意图、管理策略、Hook 信任、程序路径/权限。 |
| Hook 退出零但无记录 | payload/来源不支持可能静默忽略，网络异常可能被屏蔽；核对真实字段及 Hub 接收。 |
| 只有开始 | 是否仍在运行、等待、失败、取消或未知；结束信号及同轮关联是否正确。 |
| 提前完成 | 单次工具、子代理、流片段、临时 idle 或可继续 Stop 被误映射；核对宿主语义。 |
| 并发互相干扰、旧完成出现 | task ID 跨轮复用、序号并发、发送顺序或旧队列重播。 |
| 长任务约两分钟失效 | local-script 的 120 秒工作租期与可靠续期；提高 ttl 不能代替续期。 |
| App 移动后失效 | 注册/桥接绝对路径、旧解释器、缓存服务与新定义信任；当前安装器更新后重载。 |
| 收到但 unmatched/无提醒 | 先查来源开关与准入，再分别查提醒通道开关、亮度、输出及设备。 |
| 有完成记录无横幅 | 通知开关、系统权限、横幅、专注模式、桌面领取和投递；无界面 Hub 不保证横幅。 |
| 屏幕正常、灯具无变化 | 设备提醒开关、型号、LAN 控制、物理设备身份、网络、亮度与原厂回执，通常不需重装 Hook。 |
| DeepSeek 插件失败 | 实际 Profile、App 进程中的 dsh/pnpm/DSH_HOME、工作区、权限与依赖获取；备份不代表事务回滚。 |
| OpenCode 插件不运行 | 入口/模块/桥接/归属是否齐全，实际插件服务重启情况，不仅刷新客户端。 |
| 升级失效 | 根据 [updates.md](updates.md) 比较版本、事件格式、超时单位、路径及信任。 |

只读必要日志片段并脱敏，不读取转录找“完成”关键词。无法确定原因时报告已排除的层级与下一项有区分力的检查。原生任务失败不必然是接入故障。

## 修复与撤销

优先使用当前内置安装器，参数与检查保持同范围。识别用户主动禁用、组织策略和宿主缺失能力，这些不能靠重装解决。

直接修复拥有的文件时，先备份原字节，验证归属与结构再原子写入，保留权限和无关字段；参数优先数组，正确处理空格/中文路径，不把用户输入拼成 Shell 命令。同名归属不清时停止该写入。

修改后查格式、重复注册和第三方设置，再加载与真实验收。自建适配更新记录，不伪造 App 内置归属。仅需检查时不重置验证窗口。

失败先检查是否部分完成。撤销仅移除本次拥有的变更；用户已修改共享文件时做增量撤销，不能整份备份覆盖回去。依赖按管理器实际状态处理，保留其他 Profile、插件、来源和历史，不重置 App 或删除数据目录。
