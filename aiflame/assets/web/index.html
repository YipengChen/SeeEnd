接入说明与当前范围

Codex 提交消息后进入工作中，工具活动延长呼吸灯，回复完成后显示火苗，主动中断后取消对应提示。完成仅指“一轮回复结束”，不判断答案质量。不会保存或转发提问与回答正文。已有任务可能需要重新打开或重启 Codex 才加载配置。

本地 API 可通过鉴权的 POST /v1/events 接入，未列出的应用需要主动上报状态。 九种 AI 网页共用 Chrome 扩展及本机桥接；豆包、千问、元宝、ChatGPT 的 macOS 桌面普通聊天为实验接入，需授权后用实际客户端验证。Windows / Linux 暂不支持桌面客户端监听。

Hub 支持 USB 与 Wi-Fi 控制；在桌面 App 中关闭窗口后可从托盘恢复，退出 App 后停止监听。
