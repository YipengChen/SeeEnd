## 状态判断

- 用户发送后观察到明确生成控件，才上报 `working`；只用当前任务的新回复结束控件确认 `done`，持续确认 800 毫秒，不按正文停顿猜测成功。
- 生成中每 30 秒续期；后台 service worker 每 5 秒检查已开始的原始文档。千问和智谱另有受限后台渲染辅助，不激活标签页，不读取网络响应。
- 停止、切换会话、刷新或关闭页面撤销任务；观察中断和超时不算成功。Hub 失联停止当前任务的转发，恢复后发送一条新提问即可重新连接，不补播历史完成。
- Gemini 明确结束生成、但当前回复持续 5 秒没有可确认成功的操作栏时，上报「状态未知」并停止续期；不将中断或未确认结果算作完成。生成控件恢复或结束标记消失会重新等待，不按正文或发送按钮猜测结果。
- 来源绑定精确 HTTPS 站点和主框架，页面与扩展不持有 Hub 令牌。配置就绪、真实任务结束和输出成功分别判断。

## 返回任务与本地数据

用户在 App 点击返回时，扩展在原浏览器配置中核对并激活原任务标签页；关闭或导航后，若有已保存的正式会话地址则重新打开。不保证滚动到某轮历史回复；原配置或桥接离线、缺少有效地址时说明失败。

不读取或保存提问、回答正文、输入框文字、会话标题或认证凭据。任务会话地址与原标签页位置保存在扩展本地，最多七天／1,000 项，在任务更新或返回时清理；无痕任务不登记返回位置。网页回复标识仅在页面内存使用；发送到本机 App 的事件仅含状态及有界、不透明任务和定位标识，不含实际 URL 或正文。

会话存储保存活跃任务，结束／取消时删除；本地存储保留各来源最近结果供弹窗显示，新结果覆盖旧结果，不按天自动清理。停用或移除扩展可停止处理，移除会清除其存储；App 记录由 App 独立管理。

完整操作、隐私、证据层级及旧版实测记录分别见源码仓库 `docs/quick-start.md`、`website/` 与 `docs/chrome-web-store/privacy/`、`docs/validation.md` 和 `docs/history/web-extension-through-0.2.12.md`。
